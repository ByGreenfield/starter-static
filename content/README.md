# Content

Everything a site owner might want to change lives in this folder, separate from the components in `src/`.

- `site.json`: name, tagline, contact details, hours, navigation, contact form settings, accent color.
- `menu.json`: menu sections and items.
- `about.md`: the About page, with a `heading` in the front matter and Markdown below it.

Images go in `public/images/`. Reference them from content as `/images/<file>`.

Changing a value here and opening a pull request is the normal, low-risk daily edit.
